# moshimo-studio

「もしも〜だったら？」を 3D で検証するショート動画を、コードから書き出す仕組みです。Three.js で作ったシーンをブラウザで1コマずつ描き、ffmpeg で縦長の mp4 にします。

## 使い方
Node.js 22、ffmpeg、Playwright（Chromium）が必要です。

```bash
npm install
```

```bash
node render.cjs jihanki
```

`out/jihanki.mp4`（1080×1920、30fps）ができます。主なオプションは次のとおりです。

| オプション | 内容 |
|---|---|
| `--scale 0.5` | 解像度を半分にして速く書き出す |
| `--stills 1,5,9` | 指定した秒の静止画だけを出す |
| `--out パス` | 出力先を変える |
| `--audio-only` | 書き出し済みの mp4 に、音だけ付け直す（数秒で終わる） |

確認はまとめて1コマンドで実行できます（文法チェック、テスト、試し書き出し）。

```bash
npm run check
```

## 使っている技術
- Three.js: 3D の描画
- Playwright（ヘッドレス Chromium）: 1コマずつの書き出し。GPU のない環境でもソフトウェア描画で動く
- ffmpeg: コマを mp4 にまとめ、音を合わせる
- 自作のシンセ（`src/synth.js`）: BGM と効果音をコードで合成する。外部の音素材は使っていない
- M PLUS Rounded 1c: 字幕のフォント（SIL Open Font License）

## 設計上の判断
- **クラウドだけで作る**: PC を使わず、制作から書き出しまでをクラウド環境で済ませるため、ブラウザの 3D 描画をコマ単位で書き出す方式にした。
- **時刻だけで絵が決まる**: すべての動きを「時刻 t の関数」として書く。何度書き出しても同じ動画になり、途中の1コマだけを確認できる。
- **土台とシーンを分ける**: 共通部分を `src/` に、動画ごとの内容を `scenes/` に置き、新しい動画は1ファイルの追加で作れるようにした。
- **数字はコードから出す**: 動画に出す数字は、出典のある元の値を `scenes/<名前>.facts.js` に置いて計算で求め、字幕と合うことをテストで確かめる。出典は `scenes/<名前>.md` に残す。
- **音もコードで作る**: BGM と効果音を `scenes/<名前>.audio.js` に譜面のように書いて合成する。素材の権利を気にせずに済み、場面の切り替わりに正確に合わせられる。
- **量産しない**: 1本ごとに題材と検証内容を変える。

詳しくは [DECISIONS.md](DECISIONS.md) にあります。
